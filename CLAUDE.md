# Probate Pipeline

Private working repo for a multi-state probate real-estate wholesaling pipeline. Live and queued markets are listed in `config.yaml` (markets + expansion_queue, covering all 50 states + DC).

- The skill lives in `.claude/skills/probate-wholesale-deal/`. For the scheduled daily run, follow `.claude/skills/probate-wholesale-deal/references/daily-run.md` exactly.
- Runner (owner decision 2026-11-25): the scheduled slices A/B/C and the fast desk run as Render cron jobs (`render.yaml`, `runner/run.mjs`, `scripts/auto_slice.py`, scripted with free NVIDIA/OpenRouter models for summaries; no paid AI). The web app is `probate-dashboard` on Render behind the Emporium Investments admin login. The claude.ai scheduled tasks below are paused so only one runner works the pipeline; a Claude session is used for work the scripts can't do (letters, negotiation, attorney matters, Stripe import, the claude.ai dashboard).
- Earlier setup (owner decisions, 2026-11-21, now paused): the runner session `session_01VKtpFDZbbd6DhTxHVpZuwn` runs the scheduled daily slices and refreshes dashboard data. The fast desk session `session_01VKtpFAuYZcMNrX5sQ8wvgc` (see `.claude/skills/probate-wholesale-deal/references/fast-desk.md`; schedule: 8:47, 10:47, 14:47, 16:47, 19:47 Central) runs every 2 hours in business hours for time-sensitive work only: the handoff board for any worker, owner decisions, replies. It skips any firing while the main run is working. Any other session (including the setup session) makes design or setup changes only when the owner asks, and doesn't run pipeline slices or write dashboard datasets on its own. Every session pulls before working and pushes with rebase, never force.
- Settings: `config.yaml` (autonomy, targets, markets). Pipeline: `pipeline/deal-tracker.csv`. Per-lead files: `leads/<lead_id>/`. Daily reports: `reports/`. State legal notes: `legal/`. Attorney/title shortlists: `network/`.
- Dashboard data is built only by `scripts/build_dashboard_data.py` and must pass `scripts/qa_checks.py` before publishing. The page source is `dashboard/index.html`.
- Contact rules come from `config.yaml` → `autonomy` and the Compliance Officer. Outreach is `autonomous` (owner decision 2026-11-25), but a market sends only with `attorney_approved: <date>`, a tested sending channel, the Compliance PASS and the 90-day wait after death; until then its letters wait as held drafts. Workers decide routine matters within written limits and log them in `pipeline/decisions-log.csv`; the owner only signs and confirms earnest-money deposits. New workers start in trial (shadow mode) per `references/worker-lifecycle.md`. Never phone or text automatically, never sign for the owner, never handle bank details or emailed wiring instructions.
- This repo contains personal information; keep it private and don't copy it elsewhere.
- Nothing here is legal or tax advice; legal files list what to confirm with a local attorney or CPA.
